# SAIL Lab website

The public website of the SAIL Lab (Sustainable AI and Inclusive Learning) at UTSA, directed by Dr. Hyejeong Lee. It is published with GitHub Pages.

## What's in this repository

- `index.html`: the whole website. All the text on the site is in this file.
- `images/`: the portrait photos and the SAIL logo.

## Making a change

1. Click `index.html`, then click the pencil icon (Edit this file).
2. Press Ctrl+F (Cmd+F on a Mac) to find the text you want to change, and type the new text.
3. Click **Commit changes**. The live site updates in a minute or two.

Change only the words between the tags (for example the text between `<p ...>` and `</p>`). Leave the parts inside the angle brackets as they are.
